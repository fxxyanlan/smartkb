# 开放平台 API 文档

## 认证

所有请求需在 Header 中携带 Authorization: Bearer token，token 有效期为 2 小时。

## 限流

默认限流为每分钟 60 次请求，超出返回 HTTP 429。企业版套餐限流为每分钟 600 次。

## 主要端点

GET /v1/users 查询用户列表；POST /v1/orders 创建订单；GET /v1/orders/{id} 查询订单详情。
批量查询使用 ids 参数，单次最多 100 个。

## 错误码

400 参数错误，401 未认证，403 无权限，404 资源不存在，429 限流，500 服务端错误。

## 版本

当前稳定版本为 v1，v2 处于内测阶段，预计下季度开放。
