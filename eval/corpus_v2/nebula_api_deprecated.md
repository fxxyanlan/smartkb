# Nebula 开放平台 API 规范（历史版本 v1，已下线）

> 注意：本文档描述的是 v1 接口，已于 2025 年 6 月 30 日停止服务，仅作历史参考。
> 当前版本规范请查阅最新的 API 文档。

## 认证

v1 使用 `nebula-sign` 签名鉴权，签名有效期 10 分钟，过期需重新计算签名。

## 调用频次约束

v1 对每个应用限制为每分钟 60 次调用，超出返回 503。

## 批量查询

v1 批量查询单次最多接受 20 个 ID。

## 下线说明

v1 的调用量已于 2025 年 5 月归零，所有接入方均已迁移至 v2。
遗留的签名密钥不再轮换，仅保留读取权限用于对账。
