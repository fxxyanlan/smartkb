# Nebula 开放平台 API 规范（当前版本 v2）

Nebula 开放平台对外提供 REST 接口，基础域名为 https://api.nebula.example.com 。
所有接口均为 HTTPS，请求与响应体统一使用 JSON。

## 认证

调用方需在请求头携带 `X-Nebula-Token`。Token 由控制台签发，默认为期 6 小时，
可在控制台「安全设置」中调整为最长 24 小时。Token 过期后必须重新签发，
不支持自动续期。鉴权失败返回 401。

## 调用频次约束

平台对每个应用维度做调用频次约束，默认窗口为 60 秒，窗口内允许 300 次调用。
超出窗口上限时返回 429，并在响应头 `Retry-After` 中给出建议等待秒数。
如需提额，提交工单经审批后可提升至 3000 次/分钟。

## 幂等

所有写接口支持 `Idempotency-Key` 请求头。同一 Key 在 24 小时内重复提交，
服务端只生效一次，重复请求直接返回首次结果，不会重复扣费。

## 批量查询

批量查询接口单次最多接受 100 个 ID，超出部分将被忽略并返回警告字段。
